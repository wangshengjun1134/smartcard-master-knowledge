# SmartCard Master Knowledge Base

## 规范引用目录 (specs/)

本知识库按照智能卡(Smart Card)领域的标准规范体系组织文档，涵盖从基础标准到应用规范的完整技术栈。

```
specs/
│
├── 01-foundation/                    # 基础标准 ⏳
│   ├── iso-iec/                      # ISO/IEC 国际标准 ⏳
│   └── nfc-forum/                    # NFC Forum 规范 ⏳
│
├── 02-platform/                      # 平台规范 ⏳
│   ├── globalplatform/               # GlobalPlatform 平台规范 ⏳
│   ├── java-card/                    # JavaCard 技术规范 ⏳
│   └── etsi-3gpp/                    # ETSI & 3GPP 通信标准 ⏳
│
├── 03-management-provisioning/       # 管理与配置 ⏳
│   ├── globalplatform/               # GlobalPlatform 安全管理 ⏳
│   ├── etsi-3gpp/                    # ETSI & 3GPP 配置规范 ⏳
│   ├── gsma/                         # GSMA (eSIM) 规范 ✅
│   └── tca/                          # TCA (Trusted Connectivity Alliance) ⏳
│
├── 04-applications/                  # 应用规范 ⏳
│   ├── emvco/                        # EMVCo 支付标准 ⏳
│   ├── fido/                         # FIDO 认证规范 ⏳
│   ├── icao/                         # ICAO 电子护照标准 ⏳
│   ├── calypso/                      # Calypso 交通卡规范 ⏳
│   └── etsi-3gpp/                    # ETSI & 3GPP 应用规范 ⏳
│
├── 05-security-certification/        # 安全与认证 ⏳
│   ├── iso-iec/                      # ISO/IEC 安全标准 ⏳
│   ├── cc/                           # Common Criteria (CC) 认证 ⏳
│   ├── nist/                         # NIST 安全规范 ⏳
│   ├── pci-ssc/                      # PCI SSC 支付安全 ⏳
│   ├── sesip/                        # SESIP 安全评估 ⏳
│   └── cen-cenelec/                  # CEN/CENELEC 欧洲标准 ⏳
│
└── 06-supporting/                    # 支撑规范 ⏳
    ├── iso-iec/                      # ISO/IEC 支撑标准 ⏳
    ├── ietf/                         # IETF 网络协议 ⏳
    ├── itu-t/                        # ITU-T 电信标准 ⏳
    ├── nist/                         # NIST 支撑规范 ⏳
    └── gm-t/                         # 国密算法 (GM/T) ⏳
```
